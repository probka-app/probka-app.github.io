# Шлюз платних операцій (2026-11-26, етап 2)

Політика: усі платні виклики вимкнені за замовчуванням для всіх, **включно з власником**. Увімкнення — лише явним рішенням власника в `public.settings`:

| Функція | Ключ увімкнення | Денний бюджет (усі користувачі разом) | Лічильник витрат |
|---|---|---|---|
| ai-text (v28) | `paid_ai_text_enabled = 1` | `paid_ai_text_daily_max = N` | `service_usage` / `claude` (calls + errors) |
| voice-clone (v11) | `paid_voice_clone_enabled = 1` | `paid_voice_clone_daily_max = N` | `service_usage` / `elevenlabs_clone` |

- Немає ключів, некоректні значення, налаштування не читаються → `403 paid_disabled` / `403 paid_budget_missing` / `503 policy_unavailable`; бюджет вичерпано → `429 paid_budget_exhausted`. Платного fallback немає.
- ai-text: додатково чинна політика ролей (sys/raw/зображення/злиття — лише власник; інші — лише за `ai_public_enabled = 1`).
- voice-clone: створення клону — лише власник; видалення власного клону доступне всім (безкоштовне).
- Застереження: ai-text при порожній відповіді робить один повтор — бюджет може бути перевищено щонайбільше на 1 виклик.

## Тести (офлайн, заглушки, 0 платних викликів)
ai-text 8/8, voice-clone 9/9; попередні версії: voice-clone v10 — 3/9.

## Штатний відкат
**Не** на попередні вразливі версії. Аварійний відкат — розгорнути `supabase/functions/_safe-stub/index.ts` під ім'ям функції (`verify_jwt=false`): усе повертає 503, жодних звернень до провайдерів. Відновлення робочої версії — з цього репозиторію за погодженням власника.
