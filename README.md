# Probka

Сайт: https://probka-app.github.io

Конструктор коротких відео (формат «Рілс маркером») з підпискою та партнерською програмою.

- `index.html` — сам конструктор
- `server.js` — з'єднання з сервером (Supabase: вхід, оплата, баланс, виплати)
- `a/` — таймлайни, плашки, шрифт, приклади

Сервер (база й функції) — окремо, у Supabase-проєкті «Probka».
